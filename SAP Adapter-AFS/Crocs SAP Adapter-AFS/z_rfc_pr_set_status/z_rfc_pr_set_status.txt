FUNCTION Z_RFC_PR_SET_STATUS.
*"----------------------------------------------------------------------
*"*"Local Interface:
*"  IMPORTING
*"     VALUE(I_WEBSITE) TYPE  ZPLUMRIVER_WEBSITE
*"     VALUE(I_TARGET) TYPE  ZPLUMRIVER_PSTATUS
*"  EXPORTING
*"     VALUE(E_OLD_STATUS) TYPE  ZPLUMRIVER_PSTATUS
*"     VALUE(E_NEW_STATUS) TYPE  ZPLUMRIVER_PSTATUS
*"  TABLES
*"      TA_RETURN STRUCTURE  BAPIRET1 OPTIONAL
*"----------------------------------------------------------------------
*=======================================================================
* ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
*  PlumRiver LLC
*  Version 2.0.00
*  Delivered:  August 26, 2011
* ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
*=======================================================================

*//  Local Declarations
  DATA:  LS_HSTATUS type ZTXX_PR_HSTATUS.

*//  Begin Processing
* Initialize tables and set values for parameters
  PERFORM INITIALIZE_GLOBALS_TOP.
* Get technical (SAP) websites
  PERFORM GET_TECHSITES TABLES GT_TECHSITE
                               TA_RETURN
                        using  I_WEBSITE
                     CHANGING  GV_RC.

  IF GV_RC is initial.
    READ TABLE GT_TECHSITE into GS_TECHSITE
                           index 1.
    Select single *
         from ZTXX_PR_HSTATUS
         into LS_HSTATUS
         where techsite = GS_TECHSITE-WEBSITE.
    IF sy-subrc = 0.
*---- set old status
      E_OLD_STATUS = LS_HSTATUS-STATUS.
*---- Set new status
      perform SET_NEW_STATUS TABLES TA_RETURN
                             USING LS_HSTATUS
                                   GS_TECHSITE
                                   I_TARGET
                          CHANGING E_NEW_STATUS.
    ELSE.
*---- return message that status not found
      clear: gs_ret1.
      gv_msgid = 'ZPLUMRIVER'.
      perform SET_RETURN_MESSAGE using 'W' gv_msgid '251'
                                       space space space space
                            changing   gs_ret1.
      append gs_ret1 to TA_RETURN.
    ENDIF.   "sy-subrc = 0  [ON Select single...from ZTXX_PR_HSTATUS]
  ELSE.
*-- Technical Website name not determined.  Do nothing! this processing
*-- is sufficiently handled within subroutine GET_TECHSITES.
  ENDIF.   "GV_RC is initial

ENDFUNCTION.
