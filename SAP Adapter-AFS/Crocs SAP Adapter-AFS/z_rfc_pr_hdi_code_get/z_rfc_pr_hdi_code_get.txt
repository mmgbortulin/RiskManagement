FUNCTION Z_RFC_PR_HDI_CODE_GET.
*"----------------------------------------------------------------------
*"*"Local interface:
*"  IMPORTING
*"     VALUE(I_WEBSITE) TYPE  ZPLUMRIVER_WEBSITE
*"     VALUE(I_VKORG) TYPE  VKORG DEFAULT '%'
*"     VALUE(I_VTWEG) TYPE  VTWEG DEFAULT '%'
*"     VALUE(I_SPART) TYPE  SPART DEFAULT '%'
*"     VALUE(I_ROWS) TYPE  SYTABIX OPTIONAL
*"  TABLES
*"      TA_CODE STRUCTURE  ZSXX_PR_CODE_EXT
*"      TA_RETURN STRUCTURE  BAPIRET1
*"----------------------------------------------------------------------
*=======================================================================
* ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
*  PlumRiver LLC
*  Version 2.0.00
*  Delivered:  February 23, 2011
* ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
*=======================================================================

*//  Local Declarations
  field-symbols: <code> like line of TA_CODE.

*//  Begin Processing
* Initialize tables and set values for parameters
  PERFORM INITIALIZE_GLOBALS_TOP.
* Get technical (SAP) websites
  PERFORM GET_TECHSITES TABLES GT_TECHSITE
                               TA_RETURN
                        using  I_WEBSITE
                     CHANGING  GV_RC.
  IF GV_RC is initial.
    GV_ROWS = i_rows.
*-- Get CODE data
    Select *
        from ZTXX_PR_CODE  up to GV_ROWS rows
        into corresponding fields of table TA_CODE
        for all entries in GT_TECHSITE
        where techsite = GT_TECHSITE-WEBSITE   and
              vkorg LIKE i_vkorg    and
              vtweg LIKE i_vtweg    and
              spart LIKE i_spart.
    if sy-subrc = 0.
*---- successful retrieval of records.
      gv_msgid = 'ZPLUMRIVER'.
      write: sy-dbcnt to gv_msgv1 left-justified.
      perform SET_RETURN_MESSAGE using 'S' gv_msgid '003'
                                       gv_msgv1 space space space
                            changing   gs_ret1.
      append gs_ret1 to ta_return.
*---- update text field on transfer file
      LOOP AT TA_CODE ASSIGNING <CODE>.
        perform GET_CODE_DESCRIPTION(ZIXXPR_SUBS900)
                                     IF FOUND
                                     using <CODE>-SALESORG
                                           <CODE>-KEYWORD
                                           <CODE>-CODE
                                  changing <CODE>-DESCRIPTION.
      ENDLOOP.   "AT TA_CODE ASSIGNING <CODE>.
    else.
*---- no records returned.
      gv_msgid = 'ZPLUMRIVER'.
      perform SET_RETURN_MESSAGE using 'E' gv_msgid '099'
                                       space space space space
                            changing   gs_ret1.
      append gs_ret1 to ta_return.
    endif.
  ENDIF.   "GV_RC is initial

ENDFUNCTION.
