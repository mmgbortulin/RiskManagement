SHORT TEXT
 Conversion exit ZPRTS, external->internal

FUNCTIONALITY
 Conversion exit ZPRTS, external->internal
 Converts PlumRiver's HDI timestamp format "CCYY-MM-DD HH:MM:SS" into a
 format consistent with SAP internalformat timestamp standards:
  CCYYMMDDHHMMSS.
EXAMPLE
 March 17, 2011 @ 9:34:56 PM may be represented in PlumRiver's HDI tables
 as:  "2011-03-17 21:34:56".  In SAP,this time would be represented as:
  20110317213456.
